\usection{Implementación del Lenguaje y de su Entorno}

Antes de iniciar con la materialización del diseño realizado, fue necesario establecer un entorno de desarrollo basado en tecnologías web estándar, garantizando el cumplimiento del requisito de ejecución nativa en el navegador para facilitar el acceso desde distintos entornos. Se seleccionó TypeScript como lenguaje principal para la programación del motor de ejecución y la interfaz del editor. Para el desarrollo de la web, se optó por utilizar React debido a su capacidad de reutilización de componentes y soporte para el desarrollo de interfaces dinámicas, además de su amplia comunidad y ecosistema de librerías. Asimismo, para la renderización del grafo de flujos de datos se empleó la librería de React Flow, que proporciona una base sólida para la construcción de editores visuales de nodos y conexiones, con suficiente capacidad de customización para aplicar los estilos propios definidos en el diseño visual del lenguaje.

Siguiendo la metodología incremental seleccionada, el desarrollo se dividió en fases iterativas. A continuación, se detallan las actividades, decisiones técnicas y resultados obtenidos en el primer incremento.
